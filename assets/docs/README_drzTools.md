# Описание команд

## Горячие клавиши

Этим командам не назначены пункты меню, ленты и панелей инструментов. \
Вызов вводом в командную строку или горячими клавишами, как в **Оригинальном CAD.** 

|Команда|Название|Описание|
|---|---|---|
|drz_layNext|Следующее пространство|Переход на следующую вкладку (лист, модель).</br> Только горячие клавиши <b>CTRL+PAGEDOWN</b>|
|drz_layPrev|Предыдущее пространство|Переход на предыдущую вкладку (лист, модель).</br> Только горячие клавиши <b>CTRRL+PAGENEXT</b>|
